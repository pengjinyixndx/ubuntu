## 一、你定死的规则

- **谁是谁**：先注册的是「小螃蟹（他）」，后注册的是「银杏叶（她）」。名字固定，**不做改名入口**。
- **自己删 vs 后台删**
  - 自己删：软删，**双方都看不到**；本人可在「我的 → 恢复」里恢复；**后台一直看得见**
  - 后台删：直接删行，**双方都不知情**，不可恢复
  - **满 90 天**由定时任务真删（连图片文件）
- **只有文字类（随笔/日记）和照片类能自己删**；请求类（奶茶请愿）、亲亲**不能**
- **后台**有「被用户删的（N）」筛选
- **要实时**；**通知**先做 App 内提醒（系统推送以后再说，iPhone 需加到主屏 + iOS 16.4+）
- **「我的」页要有**：恢复、历史矛盾

## 四、踩过的坑（写下来免得重犯）

1. **我连不上 Supabase** —— 所有"验证通过"都是内存演示数据跑的，真库链路只能靠你点。
   删除 bug 就是这么漏掉的。
2. **RLS 拒绝时 PostgREST 不报错、只是一行没动** —— 写操作一律 `.select('id')`
   把影响的行取回来数，为 0 就报失败。
3. **查询里不要用可能不存在的列**（`is_admin` 那次）—— 整个查询会报错、数据全拿不到。
4. **模块级单例换账号必须 reset**，否则新登录的人看到上一个人的档案。
5. **别把手动配置当默认**（早期的 gender）—— 能自动判定就自动判定。
6. PowerShell 搜中文不可靠，查打包产物要用 Node 按 UTF-8 字节搜。
